## ✨ 功能一览

### 🗂️ 文件分类整理
上传文件夹 → **按文件类型**（文档/图片/视频/代码）、**按月份**、**按关键词**自动归类整理，支持预览后执行。

### 📝 办公模板库（14个内置模板）
| 类别 | 模板 |
|------|------|
| 📊 汇报 | 日报、周报、个人工作总结 |
| 🏢 会议 | 会议纪要、会议议程 |
| 📋 项目 | 项目计划书、OKR 目标管理 |
| 👤 人事 | 请假申请、出差申请、培训记录 |
| ✅ 日常 | 待办清单、工作日志 |
| 📄 合同 | 简易合同模板 |
| 💰 财务 | 报销单据模板 |

每个模板支持变量填充，一键生成文档。

### 🔄 文件格式转换（18种）

| 类别 | 转换类型 |
|------|---------|
| 📄 **PDF 互转** | PDF ↔ DOCX、PDF ↔ PPTX、DOCX ↔ PPTX、PPTX ↔ DOCX |
| 🖼️ **图片处理** | 尺寸调整、裁剪、旋转、添加水印、压缩、格式转换、批量处理 |
| 📝 **文档转换** | TXT ↔ DOCX、TXT 编码转换 |
| 📦 **压缩** | ZIP 压缩 / 解压 |

## 🚀 快速开始

### 方式一：下载绿色版（推荐）
1. 前往 [Releases 页面](https://github.com/liangshengwang/office-toolkit/releases) 下载 `OfficeToolkit.exe`
2. 双击运行
3. 浏览器自动打开 `http://127.0.0.1:18700`
4. 开始使用

### 方式二：源码运行
```bash
git clone https://github.com/liangshengwang/office-toolkit.git
cd office-toolkit
pip install flask pillow python-docx PyMuPDF python-pptx
python server.py
```

### 方式三：安装包
下载 `OfficeToolkit_Setup_v1.0.exe`，一键安装带开始菜单和桌面快捷方式。
